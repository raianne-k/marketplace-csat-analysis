# Data

The Olist dataset is not committed to this repository due to file size and licensing terms.

## How to get the data

1. Go to: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Click **Download**
3. Unzip the downloaded file
4. Place all CSV files directly in this `/data` folder

## Files expected by the notebook

| File | Description |
|------|-------------|
| `olist_orders_dataset.csv` | Core orders table — status, timestamps |
| `olist_order_items_dataset.csv` | Line items — seller, product, price, freight |
| `olist_order_reviews_dataset.csv` | Review scores and comments |
| `olist_customers_dataset.csv` | Customer identifiers and location |
| `olist_sellers_dataset.csv` | Seller identifiers and location |
| `olist_products_dataset.csv` | Product metadata and category |
| `olist_order_payments_dataset.csv` | Payment type and value |
| `product_category_name_translation.csv` | Portuguese to English category names |
